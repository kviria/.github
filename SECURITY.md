# Security

If you find a security problem in Kviria, please write to **hello@kviria.com** with a short description and the steps to reproduce it.

- Please do not open a public issue for a security problem.
- Please do not access, change, or delete data that is not yours.
- We read every report and reply as soon as we can.

This policy applies to kviria.com, api.kviria.com, and docs.kviria.com.

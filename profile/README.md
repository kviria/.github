# Kviria

Location infrastructure for AI to search and reason over places across the United States.

Kviria gives AI agents structured street-level geographic facts through three read-only tools over HTTP and remote MCP (`https://api.kviria.com/mcp`, `2.1.0`): single-place and multi-turn spatial lookup (`kviria`), neighborhood profiling and side-by-side comparison (`kviria_profile`), and multi-stop grounding, walking sequences, and fair meeting points (`kviria_batch`). Free to use (`600` credits/day, no credit card required).
